# SAP-1-Computer-Archirtecture
Hardware implementation of the SAP-1 8-bit computer architecture using discrete logic

While exploring foundational resources on digital electronics and computer architecture, I came across the SAP-1 (Simple-As-Possible) computer model from Digital Computer Electronics.

SAP-1 is a minimal computer architecture designed to demonstrate how a computer works at its most fundamental level. It strips away modern complexity and focuses only on the essential building blocks required for computation — including an ALU, registers, memory, a clock, and a control unit.

The system operates around a central data bus, allowing different components to communicate and execute instructions through a structured fetch–decode–execute cycle.

Rather than emulating a modern PC, SAP-1 exists to teach the underlying logic of computation: how data moves, how instructions are interpreted, and how hardware components cooperate to perform operations.

This project builds on that model to explore computer architecture through physical implementation and experimentation.
