## What is a Clock ##
The System Clock, or crystal oscillator, is a microchip component that functions as the primary heartbeat of a computer. It utilizes a tiny piece of quartz crystal that vibrates at an exact frequency when an electric current is applied, a phenomenon known as the piezoelectric effect. These physical vibrations generate a highly stable, continuous stream of electrical pulses called the clock signal. This signal alternates rapidly between high and low voltage states, creating a rigid cadence that dictates exactly when the Central Processing Unit (CPU) and other core components can execute instructions.
